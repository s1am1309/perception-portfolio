# PERCEPTION - Immersive 3D Portfolio

> An interactive 3D portfolio built with Next.js, Three.js, and React Three Fiber

![PERCEPTION Portfolio](https://perception-portfolio.vercel.app/og-image.png)

## 🌟 Live Demo

[View Live Demo](https://perception-gamma.vercel.app)

## ✨ Features

- **🌀 3D Scroll Journey** - Smooth camera transitions through interactive sections
- **⭐ Interactive Star Field** - Dynamic particles with wormhole depth effect
- **📱 Mobile Optimized** - Dual-mode system for mobile, tablet, and desktop
- **🎨 Elegant Design** - Gradient colors and wireframe aesthetics
- **🚀 Performance First** - Smart device detection and optimization
- **🎵 Immersive Audio** - Background audio for enhanced experience

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **3D Library**: [Three.js](https://threejs.org/) with [React Three Fiber](https://docs.pmnd.rs/react-three-fiber)
- **Text Rendering**: [@react-three/drei](https://github.com/pmndrs/drei)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Deployment**: [Vercel](https://vercel.com/)
- **Version Control**: [Git](https://git-scm.com/) & [GitHub](https://github.com/)

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/s1am1309/perception-portfolio.git

# Navigate to project directory
cd perception-portfolio

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
